# Ranked games use the report’s club attribution

Club Data uses the same attributed player facts for Highest Fee, Most Hands and Highest Winnings as the report summary. A mixed tournament shows the club’s share, including signed fees. Occupied cash tables remain visible when their only reportable balance is on the felt.

Recent game continuations and the snapshot fallback use the same attributed rows. This keeps Horse-only games from reappearing when the operator selects Load More.
