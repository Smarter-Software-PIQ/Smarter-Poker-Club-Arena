# Chrome Arena Lobby Controls

The selected Chrome Arena reference replaces the secondary lobby selector grid with one row of four tournament family keys. Cash retains its five existing keys, including All. Each key uses the approved blank premium plate at its native aspect ratio, fitted live labels and a real 44 pixel touch target.

Status shortcuts and Filters use a matching new empty chrome key. Every existing status remains available: three columns on phones keep Open Registration and Starting Soon readable, while desktop uses one compact row. The same controls, labels, handlers, saved filter state and advanced filter sheet remain in place. No lobby data, sort, timer, entry, favorite, engine or database behavior changes.
