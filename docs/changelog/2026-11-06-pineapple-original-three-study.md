# Original Pineapple holdings in the private study

The maintained study parser accepts exact original three-card snapshots or
reconstructs the initial set from an original retained pair plus the same actor's
recorded own discard. It validates all identity/card/DB-clock evidence and refuses
conflicts. Recovery is preflop-only before any recorded own discard; existing
post-discard holdings stay separate. No future board/outcome or opponent card is
used. Focused chronology, conflict, identity, invariance and report wiring tests
cover this optional source path. No runtime strategy is activated.
