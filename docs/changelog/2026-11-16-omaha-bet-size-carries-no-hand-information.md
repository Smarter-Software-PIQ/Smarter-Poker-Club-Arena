# 2026-11-16: The Size Of A Horse Bet Carries No Hand Information (omahaBetSizeByPublicState, Default Off)

PLO4/PLO5 cash: with the option on, the size of a Horse's own postflop bet or raise comes from public information only (street, board class, pot, chips, legal bounds, opponents, position, the heads-up opponent's measured fold-to-bet read) and a random stream of its own. Whether to bet is still the Horse's own decision. Measured tell and trace: sizing-20261116/MEASURE.md. Default off; no option-switch migration.
