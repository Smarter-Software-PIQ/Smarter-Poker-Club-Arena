# PLO witness funds the member-club wallet

Two live attempts funded the union's own wallet, then its correct admission guard refused the minimum buy-in: a union game charges an eligible member-club wallet. First-party client errors recorded INSUFFICIENT_CHIPS:100.00 for each reserved player. Neither attempt purchased a seat. Both returned their full 400-chip funding through normal claim-back and reconciled their ledger legs.

The maintained witness now uses the existing certification helper's designated member club, verifies its active chip-club identity and actual union_clubs membership, and binds funding, cash-out, claim-back and ledger endpoints to that wallet. It captures and checks the actual ordinary Join Game response before waiting for the assigned table. Existing financial admission rules and the deployed lifecycle implementation remain unchanged.
