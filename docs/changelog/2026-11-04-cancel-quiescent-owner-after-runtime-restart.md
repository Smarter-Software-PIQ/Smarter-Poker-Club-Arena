# Continue an unfinished owner cancellation after a proved runtime restart

An independent engine restart changed the serving instance while the original
announcement cancellation still retained its immutable live-process intent.
The original instance check then refused before retiring the already-masked
original release and intake records.

The existing withdrawal helper now admits this continuation only for a newer
PID1 in the same Docker container and image. Kernel birth, namespace and cgroup
evidence and both health endpoints bind the current runtime. The cutoff comes
from the original reservation and completed thaw, not a manufactured receipt
timestamp. Historical thaw identity remains separate from the fresh current
database leader. All original units must remain masked and positively empty,
including loaded service children and control PIDs. This path never stops,
signals, masks or reloads a unit.

Each cleanup execution bookends its writes against one current native witness.
Append-only witness records and retained cgroup bindings let partial cleanup
resume after another verified same-container restart. The original request,
intent, reservation, activation entry and released hold remain unchanged.
Receipts distinguish the original runtime from the runtime present during
cleanup; replay can return a separately proved current witness without changing
the historical receipt. The existing read-only observation mode exposes this
witness without adding a new reader or release path.

The original-instance refusal was reproduced before the correction. Focused
coverage includes masked/unloaded and mixed native units, read-only admission,
interrupted deletion, another restart during cleanup, subsequent receipt replay,
wrong container/image/kernel/leader/source/cutoff, and populated native units
despite retained bindings. The existing withdrawal law runs all 80 cases;
Linux-only kernel-process coverage remains required on the Linux provider.

Source qualification, protected merge and actual host continuation are separate
delivery facts. This change alone does not claim engine activation or tournament
relaunch.
