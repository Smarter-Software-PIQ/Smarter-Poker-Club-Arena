MultiTablePage keeps inactive table views mounted with display:none. The old
observer selected a visible board but read the first hand label in the whole
document. A faithful isolated inactive-header/active-board fixture reproduces
natural turn/river receipts attributed to the hidden table's hand and then
correctly discarded by the natural-wire hand fence. This generic source defect
is reproduced; its contribution to prior production unknowns is unproven.

Read the hand only from the selected visible board's closest table-page owner.
Missing ownership, missing hand labels or disagreeing owned hand labels refuse
observation. The single-board, focus, visibility, transport, natural same-hand
wire, full-animation and violation requirements remain intact. Background boards
are not newly admitted, and no assertion, duration, wait or action is relaxed.

Each existing connected interval now retains bounded sampling diagnostics even
when it admits no street: tick/eligibility counts, fixed exclusion/reset reasons,
board/card-count histograms, hand/baseline stability, first/last sample times,
maximum gap and capped-gap indication. Counters saturate at one million and gaps
at sixty seconds with an explicit cap flag. Diagnostics contain no raw cards,
player identities or hand label text and do not affect qualification. Both cash
and the shared tournament path retain the metadata in their existing artifact.

These are rAF DOM/computed-animation observations, never complete painted-pixel
proof. No production suite is manually repeated by this change.
