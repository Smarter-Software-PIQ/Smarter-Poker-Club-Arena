# Player Management Row Clipping

Rows with downline fees could lose the player role, PlayerID, last-seen status and final financial figure above the phone breakpoint. The financial stack inherited body leading that exceeded the fixed virtual row. A separate admin component also leaked padding through its global member-row selector.

Financial lines now use explicit compact leading at every width, and admin row styles belong only to the member-management component. The 116px row and virtual scroll pitch remain unchanged. Search, financial values and player-record navigation retain their existing behavior.

The existing required CSS browser regression covers a Super Agent with upline and downline fees, all fields inside each card, widths 320–1440px and both admin/roster stylesheet load orders. The original wider-width regression failed before the repair. Live publication and behavior evidence is retained in the owning task checkpoint.
