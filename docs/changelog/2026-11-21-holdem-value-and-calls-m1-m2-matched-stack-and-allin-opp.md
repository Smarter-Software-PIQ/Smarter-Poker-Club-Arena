# holdemValueAndCallsArePriced: matched-stack wager pricing and already-all-in opponent guard (2026-11-21)

- Fixed `wagerValue` in `server/src/engine/HorseHoldemValueAndCallsArePriced.ts` to pass matched exposure (`matched`) instead of Hero's unmatched surplus (`add`) to `holdemPricedFold`, and capped `holdemPricedWagerTargets` at Villain's effective stack (`effAllIn = Math.min(heroIn + heroStack, villainIn + villainStack)`) with ascending wager evaluation in `HorseLogic.holdemPricedReference` so covering raises do not hallucinate extra fold equity or escalate to unmatched all-in shoves (HVH48-D `holdem_priced_raise`: `7 fixed / 2 newlyWrong` -> `7 fixed / 0 newlyWrong`).
- Fixed `HorseLogic.ts` to skip `holdem_priced_value_raise_deferred` when the sole live opponent is already all-in (`opp.stack <= 0`) and to preserve baseline non-fold action tokens when `best.kind === 'call'` against an opponent with `0` chips behind, while still folding -EV calls (HVH48-D `holdem_priced_call`: `3 fixed / 5 newlyWrong` -> `3 fixed / 3 newlyWrong`).
- Added regression law tests in `server/src/engine/HoldemValueAndCallsArePriced.law.test.ts` pinning matched-stack fold pricing, effective-stack target capping, ascending tie-breaking, and `opp.stack <= 0` handling. Option remains default OFF with no switch-row change.
