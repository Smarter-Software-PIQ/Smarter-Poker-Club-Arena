# Bounded development own-plan diagnostics

The existing barrel continuation development CLI can retain one paired hand with `--trace-plans=true`. The optional worker callback records original validated plan-read receipts, own issued effects, controller-accepted actions and exact terminal acknowledgments. It never exports snapshots, boards or opposing holdings, injects plans, changes policy or relaxes admissions. Collection is limited to 256 events of at most 16 KiB each; unsupported experiment/count/inspection combinations refuse before dealing. No qualification or production route is added.

Focused worker tests cover actual-controller trace capture, private-data exclusion, copy isolation and refusal bounds. Missing target exposure remains inconclusive; these traces explain execution and do not establish strategy strength.
