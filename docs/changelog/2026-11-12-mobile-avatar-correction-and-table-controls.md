# Mobile Portrait Sizing And Table Controls

The previous mobile enlargement excluded six-seat tables and reserved opponent card counts that the current variant cannot deal. Six- and nine-seat cash portraits now use variant-specific fixed reservations and may zoom up to 30%. Six-seat and spectator portraits crop at the existing name plate, making faces and shoulders larger without extending behind the plate. Crowded portraits remain unchanged; photos, cosmetics, six-card, kill and tournament layouts keep their existing behavior. Seated nine-max preserves the original lower crop to avoid reducing the hero-relative height allowance. Existing tap targets and anchors stay fixed; newly revealed showdown cards use the previously approved reservation allowance.

The Lightning waiting line is white. Automatic top-up refusals stating “Lightning Session Is Unavailable” no longer show a bottom toast; diagnostics and the existing per-hand refusal guard remain. Manual requests and uncertain transport outcomes remain visible. This notification change does not repair the engine's feeder top-up routing.

Share Hand now has a visible Copy label and shows Copied after successful copying, using the existing clipboard implementation.

Validation: identical-state real-component portrait comparisons, fixed artwork across fold/reveal/turn transitions, focused unit checks, and actual browser clipboard readback. Corrected screenshots require owner approval before production publication; local previews are not live proof.
