# Native fixture image survives snapshot mirror outages

PR #9486's required native fixture check failed four times on November 4 at the image build, each time because `snapshot.debian.org` answered `503 No healthy backends` or `504 Gateway Timeout` while downloading pinned packages (PostgreSQL client, OpenSSL, X11/font libraries for Chromium). No assertion, service or source behavior was involved.

The fixture Dockerfile now runs the existing `apt-get update`, pinned `apt-get install` and Playwright Chromium dependency install as one unit with up to four bounded attempts (20–60 second pauses). APT's per-file retry count stays at 3, so a stalled mirror fails each attempt quickly instead of multiplying its timeouts; the worst case stays inside the build's existing 40-minute budget. Already-downloaded archives are reused, the same pinned snapshot, package versions, signature checks and `check-valid-until` scope are unchanged, and a fourth consecutive failure still fails the build with exit code 100. A stubbed shell check confirmed success on the first or a later attempt and failure after four.

The first hosted run with six attempts and ten per-file retries reached the 55-minute job limit without a retained log, so the attempt count and per-file retries were reduced. The accompanying job-deadline budget (recorded in the union cash schedule changelog) keeps the receipt and build log retention inside the job limit, so any further mirror failure is reported rather than lost.
