# Observe board reveals in existing tournament continuity intervals

The same bounded natural board observer now runs in the shared MTT, SPIN and
SNG spectator path, across its already required connected hand cycles before
and after network restoration. Cash observation is preserved. Each interval
qualifies independently and requires a natural same-hand turn and river; no
street is borrowed from another interval, subject or format. Existing frame
requirements and violation dominance are unchanged.

Per-subject JSON files use the existing always-retained mobile proof artifact,
including on failure, so a naturally retired tournament subject cannot overwrite
another subject's evidence. No case, account, wait, timeout or player action was
added. The observer also retains baseline frame count and the actual rAF sample
gap, to make a late first sample diagnosable. A finished first sample still cannot
qualify; DOM/computed-style evidence never establishes painted pixels.
