# The Heads-Up Big Blind Defends to Its Price (flag `huBbDefendsToPrice`, default off)

## The leak

The measurement used the real `HorseLogic.decide` at 56b5259d, with the live cash Hybrid persona and flags at live defaults. Settings: `EQUITY_GOVERNOR=off`, 80bb, 4,000 samples per hand class (`v31-r8-inputs-01Gw7a/measurement`, RANGES.md).

Heads-up, the small blind opens 71.3% to about 2.75bb. Facing that open, the big blind flats 34.0%, 3-bets 8.6% and **folds 57.4%**. T6s, 96s, Q9o and K5o all fold. The answer is almost the same at 2.5bb, 2.75bb and 3bb. A human who opens every button against a horse wins the blinds most of the time.

## The gate

Two-handed tables never reach the V72 per-seat defence. `gtoDefend72` in `HorseLogic` returns early when `dealtHorseTableSize < 3`. So `decidePreflopV7Core` ("Facing a single raise") falls through to the **V11 heads-up defence**:

```
callThresh = t53(0.30, 'call')        // 0.30 x tightness 1.0976 (grinder 1.12 x Hybrid 0.98) = 0.329
callBar    = callThresh - bbDiscount  // 0.329 - 0.06 = 0.269
V34 floor  = 0.30                     // raiser 'sb' is not 'late'
```

Neither bar reads the price or the opener's width. Both sit on the `holdemPreflopScore` ladder, and 0.27 there is about the top 43% of hands. Trace at a 2.5-2.75bb open (strength includes the per-decision jitter):

| hand | strength  | callBar | 3-bet bar | result |
| ---- | --------- | ------- | --------- | ------ |
| Q9o  | 0.21-0.25 | 0.269   | 0.69      | fold   |
| K5o  | 0.22-0.26 | 0.269   | 0.69      | fold   |
| T6s  | 0.21-0.24 | 0.269   | 0.69      | fold   |
| 96s  | 0.22-0.26 | 0.269   | 0.69      | fold   |

## The correction (`HorseHuBbDefence.ts`)

Behind the new option `HorseDecideOpts.huBbDefendsToPrice`, default **off**, the big blind continues any class that passes this test:

```
equity(class vs the top W% of the heads-up open order) x 0.8 >= call / (pot + call)
```

- **Odds.** `preflopCallOdds` is rake-aware.
- **W, the opener's measured width.** When the opponent read is engaged, W is that read's RFI/PFR posterior (`openerRangeWidth`). Otherwise W is the V70 heads-up open target: 72% cash, 76% ante. That is what the horses open (measured 71.3%).
- **Equity table.** 169 classes x widths 20..100%, Monte Carlo with 40,000 trials per cell and a fixed seed. It is generated by `server/scripts/generate-hu-bb-defence-equity.ts`, and the range order is the V70 heads-up open order. Against a random hand it matches published equities: AA 0.852, AKo 0.657, 72o 0.349, 32o 0.322.
- **0.8 realisation.** This is the centre of the published 0.75-0.85 band for an out-of-position big blind.

The correction only widens: it turns a fold of the V11 heads-up bars into a call. Value 3-bets, bluff 3-bets and every call the old bars made are unchanged.

**Scope:** no-limit hold'em cash, exactly two dealt in, the big blind facing the only open (no limp, no caller), open <= 6bb, 20-150bb effective. Tournaments, six-max and larger tables, Omaha, short deck, pot limit and fixed limit, straddles and all-in-or-fold tables are not affected.

The receipt `hu_bb_defends_to_price` is registered in `HorseDataLedger`, and the new module is listed in `HorseReferenceDecisionSources`.

Defend share by the table, against a 72% opener:

| open   | odds  | continue |
| ------ | ----- | -------- |
| 2.5bb  | 0.300 | 78.6%    |
| 2.75bb | 0.318 | 68.3%    |
| 3bb    | 0.333 | 59.0%    |
| 4bb    | 0.375 | 41.2%    |

Measured end to end with the same harness (real `decide`, live cash persona, 80bb, 200 samples per class):

| open   | flag | fold  | call  | 3-bet |
| ------ | ---- | ----- | ----- | ----- |
| 2.5bb  | off  | 57.5% | 33.9% | 8.6%  |

With the flag on, Q9o, K5o, T6s and 96s call at 2.75bb. 72o, 32o and 82o still fold.

## League

The new card is `hu_bb_defends_to_price`: heads-up, 80bb, the live cash Hybrid persona, the deal-seeded mood clock, 6,000 pairs a night. Arm A is the flag on and arm B is today. It runs through `runMatchup`, which uses duplicate deals with each seat playing both arms across the pair and mind on in sandboxes. Each run was 25,000 pairs (50,000 hands), and the seed was the only thing that changed between runs.

| runs                      | hands     | A minus B, bb/100  |
| ------------------------- | --------- | ------------------ |
| seeds 11-18 (first batch) | 400,000   | +0.75 +/- 0.70     |
| seeds 11-34               | 1,200,000 | +0.87 +/- 0.40     |
| seeds 11-50 (all)         | 2,000,000 | **+0.37 +/- 0.31** |

There were 0 illegal actions, 0 truncated streets and 0 brain fallbacks. 32.8% of pairs diverged between the arms.

**Verdict: unresolved.** The pooled result is inside two standard errors, so this is not an improvement. This card is horse against horse: the horse small blind opens a 72% range, and its postflop play does not punish a wider big blind. The leak the finding describes is a human opening 100% of buttons, and that is not measured here. No human-field heads-up card exists, because the human-field twins are six-max only.

**Six-max** is inert: 3,000 pairs (6,000 hands) at six seats and 100bb with the flag on gave 0 divergent pairs, 0.00 +/- 0.00. The flag gates on two dealt in, so the existing six-max cards cannot see it. The scenario test pins six-max, heads-up tournaments and heads-up cash under 20bb as identical with the flag on and off.

The flag stays **off**. The owner's standing rule turns a flag on only after the nightly league confirms it across runs.

- The table covers all 169 classes, matches the known equities against a random hand, gives more equity against a wider opener, and defends narrower at a bigger open.

- Six-max, heads-up tournament and heads-up cash under 20bb are byte-identical.
