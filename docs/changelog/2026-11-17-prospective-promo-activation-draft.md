# Prospective Promo Play Through activation draft

The held activation changes only the existing settings singleton to four times
fees, a 30-day expiry and the actual activation timestamp. It refuses missing
original migrations, an existing activation or unexpected grants. Existing
balances and earlier gifts are not converted into retroactive grants; the
separate winnings rule remains unchanged.
