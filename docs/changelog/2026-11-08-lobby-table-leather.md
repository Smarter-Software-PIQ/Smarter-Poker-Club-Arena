# Table Leather for the Club Arena game selector

Cash Games and Tournaments use the selected Table Leather design. The artwork
combines the existing selector's blue-lit chrome with the black diamond quilt
from the lobby game cards. The shorter plate renders at its native 1566:504
ratio. Labels, selected color, focus and game selection still use the existing
controls.

The lobby chrome browser cases verify that the asset decodes and fits at 375,
393 and 1280 pixels, and that each choice still opens its own filters.
