# The replay on real audited decisions is a required, recorded bar for every Horse option (2026-11-19)

No option, no migration, no decision change in production. Test support, benchmark, scripts and documents only.

1. The scorer refuses an inert replay. `server/scripts/audited-decision-replay.ts` (library `server/src/benchmark/AuditedDecisionReplay.ts`: `parseReplayFile`, `replayValidity`, `replayRefusals`) reads the option-switch set each arm declares (a `meta` line or `arms.<arm>.options`) and exits 2, with the reason and no score, line, row or report, when today's registry refuses a declared set (a journaled option that is off-only or unregistered today refuses the whole set, so nothing is switched), when an arm is identical to the base arm on every compared row and was not declared with `--allow-unchanged`, or when `--row` is asked from arms whose set is not declared. Before, such a replay produced identical arms and a report that read "nothing changed". It also prints, per arm, the options it switches against the base and the unchanged count beside changed / fixed / newly wrong / unjudged.
2. The Replay row. `--row <arm> --set <name>` prints the machine-read row of the option's authority file (`- Replay: fixed N; newlyWrong N; changed N; ...; set <name>; scorer <commit>`), one per audit source; the scorer commit is read from git and refused when the scorer files are not committed. `parseReplayBarRows` is the one parser.
3. The law. `server/src/engine/EveryHorseOptionRecordsItsReplay.law.test.ts`: every option authority file carries a Replay row (run, NOT RUN with a reason, or LEGACY for a replay recorded in prose only), and a file whose status paragraph says "Evidence MET" fails the build with NOT RUN, LEGACY, or newlyWrong above fixed. The four files that said "Evidence MET" on 2026-11-19 are a closed allow-list in the test. No law read these files before; this is the first, and the format lives with the scorer so there is one parser.
4. The files. All 70 option authority files gain a `## Replay` section: 50 NOT RUN, 20 LEGACY (prose replays that predate the row; for omahaFlopFacingBetEv the row cites the committed scorer's latest report, newly wrong 54 against fixed 31). No result was added that a file or an archived scorer report did not already hold. The files' sha256 change; an option-switch `on` note cites the sha256 of the file as it was when the row was written, which git keeps.

The old tooling branch (LeagueDecisionState, rule receipts, the scorer) had already reached main inside #11277; this branch merges main into it with a tree identical to main's and builds on that.
