# Member player wallet balance

The Simple Player Management roster shows each member's player wallet balance immediately above today's win/loss, in white using the same font and size as Downline. The amount uses the existing exact wallet formatter; its accessible label and tooltip identify it as Player Wallet Balance.

This supplements the primary fees figure under the owner's November 16 request. Players and agents use their player_wallet, never the agent wallet. Existing roster permissions and wallet event updates remain authoritative. No balance write, migration or engine change is involved.

Validation uses the existing member-row unit coverage (roles, zero, restricted balance and authorization), TypeScript and the existing phone containment browser checks from 320px through desktop. Publication and live receipts are recorded in the owning external checkpoint.
