# Transition tournament guarantees

The old engine created future tournaments after the first guarantee snapshot. Apply the owner’s 50% reduction to their captured IDs and original amounts, leaving the 200 entry / 25K exception and registered commitments intact. Existing reduced events cannot be halved again.

The existing Accounting qualification executes this exact migration twice on native PostgreSQL with the actual registered-contract trigger, verifies amounts and displayed labels, and rechecks the original migration’s preservation cases. Installation requires protected main and production readback. Engine adoption and a final transition census remain required before closure.
