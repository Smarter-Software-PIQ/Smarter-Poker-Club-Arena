# Satellite value-ticket accounting uses the actual admission

The weekly ownership reader incorrectly required a value ticket's original
satellite target to equal the tournament it entered. The October29
`same_value_entry_v1` contract allows another eligible event of the same native
asset and full entry value, while the original target remains immutable issue
provenance. This blocked the touched-registration proof after valid admissions.

The reader now reuses the canonical issue assertion, native-asset classifier and
entry split, then proves the exact immutable registration club, ticket escrow
debit, atomic entitlement and one admission transaction into the actual event.
The event's own split may differ from the original target. Union admissions use
the recorded member club; later membership changes cannot rewrite that history.
Unmarked historical target-only tickets and direct seats retain their strict
target checks. Nothing writes or replays a payment or changes original rows.

The source matcher retains all64 unrelated pins and pins the corrected reader
plus its3 direct helpers. Its changed bytes naturally require a new generation
through the unchanged generation owner. Old proof generations are not restamped.
The existing satellite native entrypoint now also executes the real canonical
owners against deterministic synthetic40-chip admissions with26/10/4split,
negative identity/scope/asset/backing/duplicate cases, unchanged-money checks,
metadata/ACL preservation, stale-pin atomic refusal and replay refusal.
