# Live Hybrid EV indifference

The approved per-horse indifference seeds and tie-break helper had no production consumer. The live Hybrid resolver already enforced solver adherence of one, but neither `evaluateSpot` nor `riverCallVerdict` received Horse identity, game mode or big-blind units. The facing-bet caller also ignored the selected call/fold and independently tested the sign of call EV.

The live Hybrid decision now supplies typed identity/mode/BB context to those priced EV selectors. Each alternative must be within 0.12 BB of the highest estimated candidate EV, then pass the existing stable per-horse sizing/aggression bias. A trusted tournament bubble factor can tighten that maximum to 0.06 BB. Selection retains the existing single random draw whenever the previous mixing pool required it, even when the BB cap removes alternatives. Missing context preserves the legacy selector; explicitly invalid units/identity refuse personal alternatives.

Probe candidates are snapped, scaled and legalized before pricing. Their selected amount is then executed through the existing bet bookkeeping without applying the multiplier or family snap a second time. Combo-draw raises enter the personal candidate pool only when legalization preserves the priced amount. The terminal call/fold path now consumes the selected candidate.

The bound concerns estimated EV in these selectors, not actual profit, exact solver EV or every policy return. Certified solver authority and legacy frequency charts remain unchanged; no EV is invented for them. Existing nut discipline, PLO6 dominance folds, committed/priced-in floors and subsequent V86 range/scare probes or PLO draw pumps retain their authority. Those separate policy overrides do not inherit an EV-cap claim from an earlier selector. The terminal remainder calculation intentionally uses `best` and remains unchanged. Existing RIT behavior and detached original-decision receipts are unchanged.

Regression coverage uses real Hybrid resolution and HorseLogic calls in cash and tournament modes, a fixed real near-indifferent call, and the actual legal wager producer/consumer. The wager-consumer test controls only which actually priced candidate is selected, so it tests amount preservation without claiming natural bet selection. Pure-selector cases cover identity/mode repeatability, outside-band refusal, BB scaling, invalid BBs, tournament tightening, wager deduplication and legacy random draw counts. Local passing checks are source evidence, not installation or live activation proof.
