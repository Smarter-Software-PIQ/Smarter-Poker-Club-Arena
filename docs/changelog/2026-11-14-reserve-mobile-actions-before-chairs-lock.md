# Reserve Mobile Actions Before Chairs Lock

Six- and nine-seat phone layouts now reserve the above-portrait action caption lane even when no action has arrived yet. Previously, chair placement reserved only mounted captions and avatar sizing retained the old below-plate lane. A later CHECK or FOLD could therefore appear behind the header or over another player's nameplate after chair positions had locked.

Chair placement and avatar sizing share the same static caption envelope, including its entry animation. The size cache advances to v3 so an older qualification cannot bypass the corrected reservation. Seat and avatar locks remain stable across actions, and the lowered table position and bottom controller reserve remain unchanged.

The existing real-component browser scenarios now mount without action captions, then introduce CHECK, FOLD and RAISE in the same hand and verify clear labels with unchanged portrait size. Focused reservation units cover the scaled envelope. Publication and actual live table verification are recorded separately in the task evidence.
