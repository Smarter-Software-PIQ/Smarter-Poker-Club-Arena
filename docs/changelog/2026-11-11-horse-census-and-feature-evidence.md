# Horse census and feature evidence attribution

The frozen census previously distributed an inferred group return equally across
Horse seats, creating individual outcomes that were never observed. The maintained
reporter preserves aggregate returns and cluster estimates, marks individual-seat
variance unknown, and separates calculated residuals from conservation assumptions.
It validates the frozen cohort and reads explicit research identities privately.

The fleet reporter no longer treats domain activity or generic V87 telemetry as
per-feature invocation. It binds original journals to execution and accepted
actions, consumes the bounded `deepDive` v1 rule contract, and separates effective
configuration, evaluation, eligible invocation and local input changes. Final causal
action changes remain unknown. Historical and newly declared observation epochs
are distinct; worker health cannot certify individual adoption.

Both modes run through `scripts/ops/horse-study-report.py`. The existing
`tests/unit/horseHumanStudy.test.ts` wrapper executes their Python regressions in
the maintained check route. Private report reproduction is separate from engine
publication and natural post-release acceptance. No production database write or
strategy change is made by these report modes.
