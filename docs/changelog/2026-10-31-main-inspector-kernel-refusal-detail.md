# Closed kernel refusal detail for MAIN retirement qualification

The isolated Linux retirement qualification refused before its first proposal with `main_inspector_socket_unproved`. Its kernel helper collapsed all predicate and I/O failures into that one reason, so the actual failed predicate remains unknown.

The helper now retains only a closed, internally branded diagnostic enum. The existing native failure serializer and host failure projection preserve that enum for kernel-stage socket refusals. No raw paths, process identifiers, descriptors, errors or socket rows are exported. The primary reason, two complete snapshots, zero-client admission, identity/ownership checks, limits, deadlines, no-retry contract and positive receipt remain unchanged. No readiness wait, retry or timeout adjustment is added.

Controlled existing-fixture negatives distinguish closing client rows, a changed expected binding and disappearing metadata; privacy tests reject forged/private detail and bind the native and host enum projections. This qualifies the diagnostic boundary. It does not establish the historical failing predicate, repair that unknown cause, or qualify a production cutover.
