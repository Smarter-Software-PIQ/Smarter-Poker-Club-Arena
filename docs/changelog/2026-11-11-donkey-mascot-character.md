# The Donkey Cross Character Matches Its Reward Mascot

The road character previously assembled a narrow torso, bead-like mane and elongated ears from separate procedural parts. It did not resemble the expressive donkey on the approved reward artwork.

The real crossing scene now uses an original detailed transparent mascot render, derived with the built-in image tool from `result-crossing.webp`: charcoal fur, ivory muzzle, sapphire goggles and scarf, four grounded hooves and a recognizable donkey face. A subdivided world-space mesh articulates only the legs, ear tips, trailing silk and tail. The eyes, skull and smile do not deform. A perpendicular camera-facing plane preserves anatomy at wide aspect ratios; the existing contact shadow anchors the feet. The post-booking ghost uses the same clean alpha artwork and walks the original verified route.

The existing crossing, anticipation, collision, speed, reduced-motion, receipt and completion clocks remain authoritative. Road traffic, odds, payouts, controls and headers are unchanged. The owner-requested First Street Pays label, amount and note are centered within their existing scene frame. The former exaggerated body hop becomes a small two-stride weight shift.

Validation: TypeScript; 52 existing crossing gait and terminal-completion cases; two focused mesh tests for fixed facial geometry, moving feet and drift-free resting recovery. Actual local page renders inspected at 393 and 1280 pixels, with the original isolated PostgreSQL legacy booking receipt replayed at 847 pixels for ghost continuation. No production wagers. Protected delivery and actual served verification are recorded separately in the task checkpoint.

Asset generation: built-in image tool, reference `public/assets/diamond-spins/result-crossing.webp`. Prompt requested one expressive full-body right-facing three-quarter donkey with four coherent legs, natural fur, sapphire goggles/scarf, clean transparent background and no scene/text. A second extraction retained the exact character while removing the studio background. RGBA edges were inspected against magenta; the shipped 1536×1024 WebP retains alpha.
