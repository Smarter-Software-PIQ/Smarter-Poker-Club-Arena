# Report tournament return on cost for paid entries only

The frozen November 10 Horse census divided return by cost across every
completed tournament of a currency. Free-buy events have no entry cost, so the
only cost in them is rebuys and add-ons while the prize pool is promotional.
Pooling them with paid events made the chips figure look better than paid play
supports.

Each currency block now keeps its pooled cost and return totals without a
percentage and adds two cohorts. Paid-entry events report return on net cost.
Free-buy events report their totals with no percentage. A tournament without a
recorded free-buy flag refuses instead of being assumed paid.

The report also states that the fleet enters these events against other Horses
as well as people, so a Horse percentage is mostly redistribution between
Horses less fees and is not a result against human players.

Gross cost, refunds, net cost, returns and entry counts are unchanged. Offline
reporting source: it reads no payment system, changes no payment and certifies
no wallet movement.
