# Bind Horse fleet reports to the original review

A saved reconciled verdict could previously be paired with altered journal
records. The private fleet reducer now requires the owning review's exact
version, scope, record count and manifest before attributing feature use. It
also requires the existing public-read provenance verdict before crediting
pooled reads, preserving the owner's action normalization and authority rules.

Captured coverage retains original table/Lightning speed and separates the
twelve expected variant/mode/speed cells, human participation and ability to
respond. Missing samples remain unknown opportunity coverage.

Regression coverage includes changed records with a stale verdict, malformed
review metadata, reordered records, captures without an optional key, public
read qualification, missing speed and distinct captured-cell counts. This is
offline reporting source; it neither activates a strategy nor certifies live
fleet adoption.
