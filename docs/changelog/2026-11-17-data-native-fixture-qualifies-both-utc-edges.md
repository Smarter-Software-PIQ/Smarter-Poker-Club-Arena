# The Fixed Pacific Fixture Qualifies Both UTC Edges

The native ownership scenario selects Pacific November 16, which spans UTC
November 16 and 17. Its installation records the real UTC date as the historical
cutoff. After UTC midnight on November 17, qualifying only the first source day
correctly leaves the public report incomplete.

The fixture now checks that the newly historical second edge is refused until
the original finite loader qualifies it. It seeds that edge only when the actual
fixture cutoff includes it, preserving the prohibition on future source loads.
The original public-screen wrong-club game-count assertion remains unchanged.
Production clock, installed SQL, source ownership and timeouts are unchanged.
