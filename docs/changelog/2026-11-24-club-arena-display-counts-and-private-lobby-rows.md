# Club Arena display counts and private lobby rows

Kings Club's player-facing membership and activity counts use the existing adjusted-total read. The carousel shows a placeholder while those figures arrive, and the join preview uses the same read. Measured counts still drive the level ladder and operational totals.

The Favorites filter stays saved to the account and skips the success confirmation for the filter alone. Starring or unstarring a game still confirms the accepted change.

Private Spin and Private Heads-Up creation sit behind the game headings as the first row in their game lists. Both use the existing lobby artwork and offered-board creation flow. A list without an eligible offer still opens the creation card, which explains the empty offer state. Lobby Invite actions use a painted button plate. The Spins game emblem uses the selected Chrome Rotor art.
