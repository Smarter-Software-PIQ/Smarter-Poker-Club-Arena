# Tournament Lobby Controls And Level Clock

The full tournament lobby and its table overlay use the same live Details and Blinds views. Active late-registration events show their current level. The clock uses synchronized server time and the level start committed by the engine. On a break it waits for the credited resume. The lobby reads the new level and its timestamp together when the engine advances.

All eight tabs use a 44-pixel chrome button. Current and next blinds are visible on Details. Satellites has a dedicated empty state. Rewards groups the guarantee and funding figures above a compact payout ladder with Place, Pool Share and Payout columns. Section headings use a continuous steel edge. Existing event formats, avatars, agent rosters and scrollable lists retain their own data and controls.

Mounted regressions exercise the table overlay and full route. Browser checks measure both edges of each tab at phone and desktop widths. The signed-in spectator journey visits each of the eight real panels and records each view.
