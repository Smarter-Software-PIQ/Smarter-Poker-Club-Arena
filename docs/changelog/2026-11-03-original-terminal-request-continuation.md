# Original terminal request continuation (in progress)

Unknown terminal outcomes currently lose their exact request identity when the
manager stops. The connected change retains immutable ordinary, proposal,
legacy deal, single-winner satellite and multi-qualifier satellite identities;
reusable resolver-only paths preserve committed, definitive miss and unknown.

A new event-owned durable request contract is being qualified before runtime
activation. Its execution door invokes the existing financial authority under
the canonical lane and exact manager generation, closes proven misses under the
same lock, and refuses queued stale or closed requests. Receipt insertion guards
prevent an older unwrapped caller from bypassing an event's original request.

This work is not qualified for publication yet. Native crash/concurrency proof,
admission/restart wiring and all affected checks remain required. There is no
new scheduled scanner, payer, production mutation or universal recovery claim.
