# Continue the original terminal request after transport or process loss

A manager previously retained a finishing request only in memory. An unresolved
reply stopped that manager; later admission could rebuild gameplay or wait for
legacy COMPLETING recovery without the original winner, proposal or qualifiers.

The manager now acknowledges an immutable event-owned intent before settlement.
Its execution door calls the existing payer under the original financial lane
and current lease generation. The serialized resolver reads that exact intent;
a proven RUNNING miss closes it before gameplay can resume, fencing queued late
sends. A COMPLETING miss retains the original continuation. Startup adopts the
original request before admitting any dealer and resolves it before any exact
replay. Receipt-only cleanup remains the same nonfinancial tail.

COMPLETING discovery uses the existing manager admission immediately when an
original intent exists. The existing F06 custody proof accepts that state only
with an original intent and current generation; every hand, park and witness
check remains. Legacy recovery cannot reconstruct a different request over it.
No new payer, periodic repair mechanism, hot-table foreign key or runtime patch
is introduced.

Focused tests cover all five request kinds, unknown reads, immutable identity,
pre-send lost acknowledgements and cleanup dispatch. Native PG17 qualification
uses a funded SNG and the actual financial functions to prove exact replay,
COMPLETING custody, true concurrent close/queued-send serialization, successor
adoption and stale-generation refusal. Connected HTTP cases also run the actual manager-authorized prepare, execute
and resolver clients for MTT, SNG, Spin, single-winner satellite and qualifier
satellite. Each loses a committed TCP reply, verifies exact recipients and
economics, then replays the same durable execution and compares every financial
relation. Satellite fixtures include the captured current lease dependencies;
no fake claim or generation grant substitutes for them. Legacy/proposal deal
dispatch remains covered by focused runtime tests, not native deal settlement.
The combined qualification is wired into required accounting shard 4. The synthetic final roster/isolated clock advance do not prove live
hand continuity or universal outage recovery. Production installation and engine
adoption remain the owning delivery's separate requirements.
