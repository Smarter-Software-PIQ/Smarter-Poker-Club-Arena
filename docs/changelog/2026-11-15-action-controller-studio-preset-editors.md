# Edit Action Controller Presets In Table Studio

Table Studio now provides a separate **Change Default Button Amounts** tab immediately below the controller color selector. Opening it shows all four preflop multipliers and all four postflop pot percentages in the same section. It reuses the existing account-wide editor, validation, Apply and Restore Defaults actions and persistence owner. Previously this entry point explicitly rendered only colors, making the preset controls unavailable on the screen the owner used.

The real Studio browser regression edits all eight values and reopens the screen. The existing production preference proof now edits through Studio itself and verifies account storage and cold rehydration. Controller sizing and wager submission are unchanged.
