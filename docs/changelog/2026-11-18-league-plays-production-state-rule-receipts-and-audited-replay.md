# The league plays production's decision state; PLO rule firings name their decision; one audited-replay scorer (2026-11-18)

No option, no migration, no decision change in production.

1. League decision state (benchmark only). `server/src/benchmark/LeagueDecisionState.ts` gives every league Horse decision the state the live table builds in `ServerTableEngineTurns.scheduleHorseAction` (schema version, legal menu priced by the league's own validator, toCall, wager bounds, betting structure, real investments, no opponent cards). Before it, every rule that guards on the live contract returned unchanged in every league arm, so league cards measured a Horse production never fields. Pinned by `ALeagueDecisionStateIsProductions.law.test.ts` (key by key against the real live builder) and `ALeaguePlaysProductionsBrain.law.test.ts` (each always-on rule fires; 0 illegal, 0 fallbacks). Originally 2f53a80d550 (session 01Gw7aDt), re-applied on current main.
2. Per-decision rule receipts. `BrainTelemetry.noteDecisionRuleReceipt` records, inside the decision's own fire scope and under the same gate as a fire, the action a receipted PLO rule was given and the action it left (omaha_river_non_nut_raise_flatted / \_fold_restored, v81_river_set_big_bet_fold, omaha_turn_set_pound, omaha_nut_class_pot_wager). The worker's FAST decision journal carries the list as `ruleReceipts` only when non-empty; every other record is byte for byte what it was. A DEEP second look (withSecondLookFireCapture, added on main 2026-11-16) records nothing. Originally 564bf6b85ea. The nut-class receipt test now opts the rule in (it ships off since #10989), as the rule's own test does.
3. Audited decision replay scorer. `server/src/benchmark/AuditedDecisionReplay.ts` + `server/scripts/audited-decision-replay.ts`: reads the audit2 decisions.csv (+ its hands.jsonl) and the WooWoo audit decisions-full.csv + decision-to-finding.csv, joins a counterfactual replay BY DECISION NODE (hand, seat, street, the seat's own decision index on that street), judges audit2 with its own analyze.py rules (EV in bb) and the WooWoo audit verdict-only (it declares no EV), and reports changed / fixed / newly wrong / still wrong / unchanged per arm and per rule receipt. `docs/horse-option-authority.d/README.md` gains the replay-bar line every option authority file carries. Tests use synthetic, anonymized rows only; the tool reads local evidence files and no database.
