# Full-Width Tournament Headers And Waiting-Game Defaults

Tournament rows now lead with one full-width header containing the format icon, complete title and variation, and any guarantee in a bold silver frame using the title's font. Metadata, buy-in, players and status remain aligned beneath it. Compact and wide schedules share this header; responsive column shedding updates the wide header's span from the columns actually displayed.

The former small duplicate guarantee marker is removed from compact metadata. Pure freezeouts retain their snowflake, and combined bounty formats retain their money bag. Black glass, format rails, pinned red frames, clocks, static Game headings, detail selection and existing cash rows remain intact. Favorites stay centered in the metadata section below the new title band.

Spins, Sit N Go's and Satellites each default independently to Players, highest first. Running or unavailable seat-first games continue below waiting games. MTT keeps Recommended and saved explicit sort choices remain respected.

Validation covers full-width title/guarantee placement, responsive spans, unchanged pre-commit selection, format icons, MTT order/clocks and all three waiting-game defaults. Normal client compiler, copy guards, protected checks and publication apply; no engine or database change is required.
