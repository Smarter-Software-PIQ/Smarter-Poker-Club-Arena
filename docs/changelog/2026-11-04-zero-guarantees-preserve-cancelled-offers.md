# Zero guarantees preserve cancelled offers

The November 3 cash-guarantee migration was refused atomically because four of its fourteen original empty offers had since been cancelled. The replacement preserves the original values and financial checks for all fourteen, accepts never-started empty cancelled rows as historical witnesses, and updates only eligible unstarted offers. It does not reopen or edit cancelled events, manufacture attendance plans for them, or change satellite seat guarantees.

The never-installed original is marked superseded through the maintained applier and ledger contract. Its SQL body stays intact; migration history is not fabricated. Install only the new protected replacement through Apply Merged Migration.

Native PostgreSQL qualification preserves the all-fourteen eligible path, verifies all four cancelled rows byte-for-byte and ten retained attendance floors, refuses cancelled rows with pools, roster, entitlements, a start, or changed guarantee, and retains existing date, ACL, funding and satellite-seat coverage. This is isolated qualification, not production installation or engine adoption.
