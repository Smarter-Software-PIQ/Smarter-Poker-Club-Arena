# tests/split-late-return-owns-its-leg.law.test.ts

A split late return owns exactly one wallet-to-bank journal leg even when the original payer suppresses automatic member journaling. The scoped trigger restores the caller's ledger declaration and original-debit output. The maintained PG17 regression executes the actual trigger, member writer, bank autoledger, enrichment, tally and deferred invariant in isolation, fails before the repair, and passes inherited and ordinary caller modes including repeated same-transaction returns. Production receipts and money are never replayed by this change.

The same regression also measures every transaction-local setting the split return touches, against the exact live body (b4d29a31) and the never-installed 20261109132114 postimage (c1b18844): several returns in one transaction, live cash-funding reads interleaved with returns, a failure caught inside the return, a failure that escapes it (caught by the caller and uncaught), and the outer commit. On the live body only `app.cash_original_debit_ledger` differs: after a return it names the return's own leg. Every live reader clears that key before its own debit and reads it immediately, so no live ledger leg, funding read or correlation changes.
