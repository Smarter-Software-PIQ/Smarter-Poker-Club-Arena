# tests/a-backup-certificate-replays-todays-incidents.law.test.ts

A Backup certificate replays the day's incidents before the 03:30 selection can take a candidate (owner order 2026-11-19). cmd_certify runs trial_regression_replay (server/standby/standby-trials.sh) on the restored copy before the engine boots, and a failed or missing replay withholds the certificate. The replay checks that the candidate's free-horse picker reads fn_horses_at_tournament_reservation_budget and that the read agrees with the seat door on predicate, threshold and the copy's data (incident eaafbbfb); that the hand-gap grader leaves out maintenance breaks, tournament breaks and hand-for-hand while still grading an ordinary pair (incident 1e532243); that fn_ca_engine_cutover_watch and the 03:00 readiness check owe the build merged by the candidate's own freeze start minus SETTLE (incident 076ff467); and that fn_ca_alarm_drill records its run in ca_detector_runs (incident 316ed735). Each check is armed by the migration that fixed its incident. The replay is one transaction, always rolled back, with live-table triggers off. Native proof: scripts/ci/test-backup-regression-replay.py.
