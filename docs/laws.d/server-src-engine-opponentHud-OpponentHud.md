# server/src/engine/opponentHud/OpponentHud.law.test.ts

The Horses' lifetime public opponent profile (OPPONENT HUD, option omahaOpponentLifetimeHud, default OFF): no card that was not shown at showdown can enter a profile (the hand record copies only seat, userId and stack from each player; a mucked showdown reveals nothing); one formula for every opponent, person or Horse, with no kind flag, roster flag, name or user-id literal in the path; a stored lifetime profile answers at an opponent's first decision of a session; there is no sample cliff (a statistic contributes from its first observation with weight n / (n + k) toward the population prior); the helpers never throw into a decision (a malformed packet installs nothing, an unregistered statistic answers the prior); the packet is bounded; hand-level recall returns his past instances of a spot with what he did and what he showed. A new opponent starts from the population prior of his stake band and game (the band rate only with at least 200 opportunities, k always the family k).
