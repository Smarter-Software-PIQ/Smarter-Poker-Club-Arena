# server/src/engine/aHeldTableThatNeverLiftsIsStalled.law.test.ts

A seated table held past its bound by a boundary owner (terminal closeout, an unclaimed tournament move) or by a retained original that never started is a stalled table on /health, named with who holds it; a scheduled, self-ending pause (hourly break, final-table deal, weekly payout, halt, operator floor, deal hold, FSM pause) is never one, hand-for-hand only past ten minutes, and these tables stay out of the liveness verdict so nothing here restarts the process.
