# tests/promo-chips-fund-cashier-tickets.law.test.ts

Owner November 12, 2026: agents can send cashier tickets to their downlines using promo chips, 50 max. A promo ticket debits the sender's promo wallet into the ticket escrow, its receipt counts toward the same 50 chips per downline seven day allowance as a promo send and a cancelled promo ticket returns to the promo wallet. The cashier previews that allowance, sends promo tickets in one batch call and recovers them by retry key. The weekly and daily digests count a promo ticket as promo given and the statement's Ticket filter returns its receipt.
