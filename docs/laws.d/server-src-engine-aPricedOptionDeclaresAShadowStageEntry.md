# server/src/engine/aPricedOptionDeclaresAShadowStageEntry.law.test.ts

A priced Horse option declares a shadow stage entry or states why it cannot be staged (2026-11-24, HOLD'EM SHADOW): every registered option whose name says it is priced (/pric/i) and that takes shadow or on_shadow is listed in OPTION_SHADOW_STAGE (HorseOptionShadowStage.ts, one line, e.g. holdemStage(['nlh_cash'], ['river'])) or in OPTION_SHADOW_STAGE_UNSTAGED with a non-empty reason, never both; a reason names a registered shadowable option; every entry lists at least one known stage game (4, 5, nlh_cash, nlh_lightning, nlh_tournament); and the Hold'em options meant to be trialled (holdemValueAndCallsArePriced, holdemTournamentAllInCallIsPriced, cashDefenceTrimColdCalls) are staged. So a new priced option cannot reach live tables without a watched shadow trial path.
