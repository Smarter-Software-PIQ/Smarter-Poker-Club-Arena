# server/src/engine/anUnclaimableMoveDoesNotOutlastTheLastPause.law.test.ts

When the last real pause on a table lets go (add-on break, :55 tournament break, maintenance freeze, hand-for-hand, weekly payout, final-table deal, terminal closeout), the table deals. An UNCLAIMED tournament-move owner on a table carrying a retained, never-started original cannot hold the pause gate, because it can claim only between hands and that table gets there only by playing the original. A CLAIMED move owner, and a move owner on a table that is between hands, still hold it. Every release path in ServerTableEngineBase asks the single `tournamentMoveHoldsRelease()` predicate, never the raw owner set. Measured on Union Mystery Bounty (PLO5) 7576aeb1, table 41d47e9d, 2026-11-05: the table was dark from 23:05 to 23:12:05, and only the 600s pause safety timeout freed it.
