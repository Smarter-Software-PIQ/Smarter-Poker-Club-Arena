# server/src/maintenance/aBreakTimingNeverFreezesATournament.law.test.ts

A break landing a few milliseconds early or late never freezes a tournament: a reserved hand that never started, held at the pause gate by any owner (hourly break, closeout or qualifier boundary, activation boundary; an unclaimed table move never holds it at all), is parked and never a live hand a waiter must outlast, and is dealt intact when the last pause lifts; and the :55 tournament break that would overlap the coming hourly break ends exactly with it, never partway through it.
