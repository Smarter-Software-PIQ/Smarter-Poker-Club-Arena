# tests/hit-and-run-club-setting.law.test.tsx

Hit and run, the club's choice (owner 2026-11-06): a club's owner, co-owner or admin may switch the hand count off for the cash games the club hosts, or choose 5, 10, 15 or 20 hands (the same number is added per double), only through fn_set_club_hit_run; switching it off clears open countdowns at once. The hand a countdown starts, the player is told ("You Are In Profit. Play 10 Hands Before You Can Leave"); a count already running when the table opens is not announced again.
