# server/src/engine/HorseCallsOnHisShownRecord.law.test.ts

holdemRiverCallVsMeasuredBluffIsPriced and holdemMultiwayFlopSmallBetCallIsPriced (default OFF) add a call only on the bettor's own record of called bets shown at showdown: with no record (opponent memory off) neither option changes any hand; against a river bettor who bluffs far beyond balanced, once his called bets have been shown, folds become calls; against a bettor who never bluffs, the option never calls and changes nothing.
