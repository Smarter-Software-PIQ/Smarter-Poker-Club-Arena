# tests/an-authority-doc-states-the-live-switch.law.test.ts

An option's authority doc states the switch state production is in. docs/horse-option-switch-state.json is the committed copy of public.ca_horse_style_switch as the last verified switch write saw it: scripts/ops/horse-option-switch.mjs set rewrites it in the operator's checkout after the readback, and `snapshot` rewrites it from the live rows (read-only). The law fails when a doc's machine-read State (`**State: ...**`) disagrees with it: a doc that says LIVE ON needs an `on` row, a doc that says OFF needs no row or an `off` row, shadow and on_shadow need that row. So a switch write and its doc land in one PR (Antigravity Coordinator hardening item 1, 2026-11-23; claimed and built by the Horse SWITCH lane). CI never reads the database.
