# tests/a-superseded-migration-that-never-installed-leaves-the-active-chain.law.test.ts

An ordinary migration that merged, was refused at install (nothing applied, no schema_migrations row) and was replaced by a later file that IS installed leaves supabase/migrations/ for supabase/retired-unapplied/, byte-identical and sealed by sha256 in SUPERSEDED-UNINSTALLED.sha256, so the daily engine selector's contents guard (required_by) never requires a version that must never run, and the guard itself stays strict. The superseding installed file stays active, exactly once. First case 2026-11-09: 20261109010948 (#10142) and 20261109064934 (#10148), both refused 25P04, superseded by the installed 20261109073642 (#10150). Third case 2026-11-09: 20261109152550 (#10187), refused before any write (PERFORM at top-level SQL), superseded by 20261109163346 (#10200); its escrow-shadow patch is owned by the installed 20261109151859.
