# server/src/engine/anOmahaBareOverpairContinuationIsPeoplePriced.law.test.ts

omahaBareOverpairContinuationIsPeoplePriced (default OFF) prices the heads-up PLO4/PLO5 cash flop continuation of the bare big pair that checked out of position and faces one bet on the Horse's equity against the bettor's people-measured flop range (the flop pressure cap's own price) instead of the sampler's aggressor tiers. On the audited heads-up flop decisions the law holds: it prices only the continuation's own spot and never a re-raised pot; a decision it does not price is identical; it never produces a raise; off, or without the bare-overpair check, it decides nothing; the verdict takes the people equity as given (no tier, no lean), more equity never folds a call and an unusable number is ignored; the code reads no identity.
