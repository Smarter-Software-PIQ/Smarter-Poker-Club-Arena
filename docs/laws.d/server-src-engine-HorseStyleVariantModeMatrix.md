Every supported Horse style (tag, lag, balanced, tricky, grinder, hybrid), in all nine variants and both modes, goes through the production resolver (`resolveHorseHybridProfile`) and the decision worker (`DECIDE_FAST`) on a state dealt by a real `HandController`, and must return a legal action the controller accepts, with no fallback, and with every per-decision upgrade counter the activation manifest declares for that variant and mode (01, 02, 06; 07 in tournaments only). A stored legacy style must resolve exactly like a Hybrid row. Guards against a style, variant or mode branch silently withholding an approved upgrade, and against the manifest and the brain drifting apart.
