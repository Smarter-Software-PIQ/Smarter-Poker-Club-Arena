# server/src/tournament/aFinishThatTimesOutBacksOff.law.test.ts

A tournament finish the database cancels at its 45-second statement ceiling (57014) backs off: consecutive timeouts of the same finish wait the base five seconds, then double to a five-minute cap, a committed settlement or a materially different finish starts again from the base, and each growth is logged once with the tournament and the new delay. A busy lane (lock timeout, 55P03) and the maintenance break's own deferrals (PLATFORM_FROZEN, TERMINAL_MAINTENANCE_RESERVATION_BUSY) keep the five-second pass. One admission sends a timed-out settlement once, not five times, and the resolver still decides it. On 2026-11-17 tournament 4cea3f54 (547 entries) timed out on a flat five-second retry for ninety minutes, about 100 attempts, each holding a shared wallet row lock that stalled every cash table.
