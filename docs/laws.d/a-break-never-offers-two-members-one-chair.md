# server/src/tournament/aBreakNeverOffersTwoMembersOneChair.law.test.ts

A break never offers two members one chair. When a break member's chair was taken, `repairTournamentBreakDestinations` chose the replacement from a board of seated players and roster chairs, which never shows the chairs promised to the break's other unlanded members, so every member replaced in one pass was offered the same chair: on 2026-11-27 07:22 to 07:27 UTC the breaks of tables 32756123, 64f30f03 and 58f82b7f amended three members each to one chair (0ec2f753#8, 0c9285f3#1, 0c9285f3#8), the first landed and every other was refused "tournament move destination seat is occupied", twice each, because a break attempt was always dispatched as an outcome already unknown. A replacement is now chosen with the other unlanded members' chairs reserved, a chair an earlier unlanded member holds counts as taken, an attempt id this manager minted and never sent is sent once when the door refuses it (any other id keeps its replay), a gap move whose destination a pending break holds waits for the next pass, and door reads never take the pre-move board prefetch.
