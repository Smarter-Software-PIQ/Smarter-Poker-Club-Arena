# server/src/engine/anOmahaFlopCallTreeIsFast.law.test.ts

The PLO4/PLO5 flop call tree (omahaFlopRealizationIsPriced, default OFF) scores hands with HorseOmahaFastScore, which orders random PLO4 and PLO5 hands on flops, turns and rivers exactly as HorseEval.scoreOmahaHiPartial (ties included; a river score built from the turn score equals the full one). The committed fixture (32 real 4+-way flop decisions, public snapshot and the deciding Horse's own cards only, and 16 heads-up league decisions) gives the recorded EV and call exactly. Over the multiway fixture the tree costs under 0.6 of the frozen tree it replaced (measured 0.3-0.4), alternating rounds with the fastest round of each kept (src/testing/relativeCost.ts), so no millisecond bound is asserted.
