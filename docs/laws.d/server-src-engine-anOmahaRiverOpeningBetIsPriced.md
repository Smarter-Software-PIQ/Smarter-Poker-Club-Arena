# server/src/engine/anOmahaRiverOpeningBetIsPriced.law.test.ts

The heads-up PLO4/PLO5 cash river opening bet (omahaRiverValueBetInPositionIsPriced, omahaRiverBluffIsPricedOnBlockers, default OFF) prices a final river check on his measured range with exact card removal: the strength bins' masses sum to one with and without the Horse's cards, and a nut-flush blocker empties his nut-flush bins. With no record (the equilibrium fold B / (P + B)) a hand with no showdown value and no blocker gain never bluffs; his own public river fold record moves the fold rate and dominates as it grows. A bluff stands only where the Horse's cards raise his fold share (math and blockers), a value bet only in position; off, or out of its spot (multiway, PLO6, tournaments), the rule returns the same decision object and it changes only a check into a bet. Another user id, name or person/Horse flag with the same public record decides the same.
