# tests/a-losing-roster-is-not-a-winning-agent.law.test.ts

The union integrity sweep scored an agent roster on one 24-hour window with no memory, so a high-variance player who loses over the week raised an `agent_roster_winning` alert on every winning day: 12 alerts sat open from 2026-10-24 on three agents whose rosters had no edge over 7 days, and the only close path required the roster list to be empty. This law pins `fn_union_agent_roster_sustained_edge`, which measures a roster over N days scoped exactly as the sweep scopes it (union tables and tournaments, horses excluded) against the sweep's own ratio (net above 10x rake). The sweep flags a roster only when its 24-hour edge is also sustained over 7 days, and an open alert closes on a re-measurement when no roster it names has a sustained edge, it names no co-seating pair, and none of its direct transfers is a dump. A co-seating pair stays open for a person to review. The helper is service-only, and the sweep change is pinned by preimage and postimage so a re-apply is a no-op.
