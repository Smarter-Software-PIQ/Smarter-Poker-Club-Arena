# server/src/engine/horseDecision/aFallbackSaysWhichPathRejectedIt.law.test.ts

A horse decision that falls back to the legal check or fold names the path that rejected it (2026-11-09). `poker_horse_decision_fallbacks_total` carries one `reason` label from a fixed closed set: `expired`, `capacity_refused`, `shard_failed`, `shard_stopping`, `enqueue_failed`, `validation_failed`, `result_refused`, `post_result_failed`, `unknown`. The reason comes from the error's class or a stamp set where the rejection is raised, never from message text, and an unrecognised error is `unknown`, never a guess. On 2026-11-09 the alert reported 91.2 fallbacks a minute while the worker's expiry, queue and error counters read zero, and metrics could not say which path was responsible. The label identifies the path; it is not a diagnosis of the cause and it changes no gameplay.
