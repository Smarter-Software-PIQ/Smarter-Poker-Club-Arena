# tests/a-window-migration-waits-for-the-daily-break.law.test.ts

A migration declaring "-- @install-window: daily-maintenance" is refused as queued by the ordinary applier and installed only by the daily 03:30 America/Chicago run of stage-engine-release.yml inside the confirmed 04:00 freeze: one transaction and one attempt per file, the break-window override reason recorded by the existing DDL guard, 1 s lock_timeout, 5 s statements and an 8 s budget asserted before COMMIT, no sleeps, blocking advisory locks or LOCK TABLE loops, and a refused file is skipped alone (named, still queued) while the files behind it are still sent once each; only an UNKNOWN outcome stops the run. A file may name the hot relations it locks on one "-- @locks: schema.relation, ..." line (an unparseable value is refused before waiting): the installer sends undeclared files first, oldest first, then declared files grouped by shared relation and oldest first, and a skipped file's line and the verdict name the relation it lost; the declaration orders only and never widens a timeout, earns a retry or changes the transaction.
