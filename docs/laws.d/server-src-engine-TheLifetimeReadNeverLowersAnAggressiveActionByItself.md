# server/src/engine/TheLifetimeReadNeverLowersAnAggressiveActionByItself.law.test.ts

With omahaOpponentLifetimeHud on, the lifetime opponent read never lowers a raise to a call or a bet to a check by itself: at the four sites where it did on the Nov 20 journals (the flop/turn V53 pressure raise, the preflop opener / re-raiser exploit, the flop/turn bluff baseline's station read, the river bluff baseline's station and fold reads) the opponent is also read as without it (receipts muted, so the presumption receipt stays gone); a lowering stands only when a priced comparison on his lifetime response says so (raise against call, bet against check), and where none can be priced the lifetime read is not consumed at that site. With the option off no site changes (lane OPPONENT-HUD, Nov 21 2026).
