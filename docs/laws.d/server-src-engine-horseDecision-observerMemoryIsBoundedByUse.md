# server/src/engine/horseDecision/observerMemoryIsBoundedByUse.law.test.ts

A decision shard's horse observer banks are bounded by use, not by arrival (2026-11-05). Every shard learned every completed hand on the floor into a bank for every horse it had ever served, so banks for horses that no longer decide on that shard kept growing and the engine climbed about 150 MB every seven minutes to 11 GB. A bank that has not decided for `DEFAULT_IDLE_MS` (20 minutes) is evicted and no longer learns, entries are kept in least-recently-run order under `maxEntries`, an over-capacity bank resets after learning, and each shard publishes `poker_horse_decision_worker_heap_used_bytes{shard}` so the bound is measurable. A horse that decides again starts from its durable read, exactly as any player who returns to a table.
