# server/src/engine/horseDecision/everyUpgradeHasALiveSwitch.law.test.ts

The Horse option switch carries only registered decision options, fleet-wide, and does nothing until a row is set: the database whitelist equals the engine registry; authority-gated options, phase packs, Pillar 2, R7/R8, held-out packs, All-In-Or-Fold widening, blind steal, the withdrawn PLO6 rules and preflop range changes are refused by name by the registry, the database functions and the worker; a real decision with an empty switch is handed exactly what it was handed without one; set and clear write the audit table with actor and time and only service_role may call them; an unreadable or malformed read leaves every option at its release default; and a replayed decision uses the switched set its own record carries.
