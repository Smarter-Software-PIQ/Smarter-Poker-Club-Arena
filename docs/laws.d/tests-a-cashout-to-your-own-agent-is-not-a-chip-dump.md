# tests/a-cashout-to-your-own-agent-is-not-a-chip-dump.law.test.ts

The union integrity sweep kept a money_integrity incident escalated from 2026-11-16 on "direct chip transfers" that were all players cashing out through the club's cashier or the agent credit route: a cashout_request_escrow plus a cashout_approved for one cashout (so each cashout counted twice), an owner approving a cashout as cashier, an agent claiming credit back. Its deny-list excluded `cashout` but not the cashier's documents, its agent test looked only at the sender, and it had no close path, so 14 alerts sat open from 2026-10-23. This law pins one definition of a player-to-player dump (`fn_union_transfer_counts_as_dump`) in which the cashier documents are the cashout itself and a movement to the sender's own agent is the agent route, while a transfer between unrelated players still counts. The sweep reads only that definition, and it closes an alert whose only signals are direct transfers once its own window, re-read through the same definition, holds no dump; an alert that also names a winning agent roster or a co-seating pair stays open for a person to review. Any later redefinition must carry all of it.
