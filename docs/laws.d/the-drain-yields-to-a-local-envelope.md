# server/src/services/supabase/theDrainYieldsToALocalEnvelope.law.test.ts

The hand projection drain never sends fn_project_hand_side_effects for a hand whose post-commit envelope this process is applying (claimed at the commit reply by handHistory.ts and for the duration of processHandPostCommitObligations, bounded by LOCAL_ENVELOPE_CLAIM_TTL_MS): it defers the row with no round trip, keeps the table's later rows behind it, and is woken when the claim is released, so a locally settled hand costs one projection call (two for a raked hand, the designed banking pass) instead of racing the engine for the table mutex and costing a second full call (measured 0.27 extra calls per hand on production 2026-11-27); a failed envelope call still releases its claim and an expired claim never holds a row, so the drain remains the crash successor.
