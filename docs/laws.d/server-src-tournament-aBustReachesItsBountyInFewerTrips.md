# server/src/tournament/aBustReachesItsBountyInFewerTrips.law.test.ts

A PKO knockout that the knockout door accepts is broadcast to the table after at most six sequential database round trips inside `eliminatePlayer` (nine before 2026-11-05). The replay guard and the pricing row travel together, the payer reuses the exact obligation the door just proved instead of reading it again, and the display names travel with the payment. In the bust stage the playing count and the first knockout order page travel together, and a freezeout opens no rebuy decision, so a freezeout bust reaches its first elimination after three trips (five before). Money still moves exactly once, through the same payer, with the same arguments. `poker_tournament_elimination_sweep_step_ms{step}` on the engine's `/metrics` shows the time of every named sweep step in production.
