# server/src/engine/horseDecision/theSwitchRefusesWhatTheServingEngineDoesNotRegister.law.test.ts

The Horse option switch never writes a row the serving engine cannot parse (the reset trap): the engine publishes the option names and states it registers, keyed by its release sha (`optionRegistryPublisher.ts` through `fn_ca_horse_option_registry_publish`), and `fn_ca_horse_option_switch_set` and `fn_ca_horse_option_switch_record_evidence` refuse a name or state that any fresh published registry does not list, while clear is never refused. Guards against a switch row, even off, for an option the serving release does not register making that engine drop every switched option to its release default, and against either half (the publisher or the database guard) being dropped quietly.
