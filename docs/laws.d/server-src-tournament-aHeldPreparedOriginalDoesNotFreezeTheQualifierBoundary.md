# server/src/tournament/aHeldPreparedOriginalDoesNotFreezeTheQualifierBoundary.law.test.ts

A retained tournament hand that never started is held at the satellite qualifier boundary, not counted as a hand in the air: a continuing field releases every table, a qualifying field settles over it while it is still proven unstarted (aQualifyingFieldSettlesOverAHandThatNeverStarted), and an unresolved field or a changed held original keeps the boundary
