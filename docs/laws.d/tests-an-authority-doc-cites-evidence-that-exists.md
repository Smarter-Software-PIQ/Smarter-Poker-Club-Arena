# tests/an-authority-doc-cites-evidence-that-exists.law.test.ts

An option authority doc (docs/horse-option-authority.d/) cites evidence that exists. Every repo path a doc cites (a token starting at docs/, server/, scripts/, tests/, src/, client/, supabase/ or .github/ and ending in a file extension) must exist in the checkout, at the root or under server/. Absolute Mac paths, which CI cannot see, and archive-relative paths that only look like repo paths are listed in docs/horse-option-authority-external-evidence.json with the date they were checked by hand and whether the file was found; a not-found entry needs "EVIDENCE FILE NOT FOUND (checked <date>)" in its doc, and an entry whose doc no longer cites its path fails as stale. Paths are read by scripts/ops/horse-authority-evidence-paths.mjs. Added 2026-11-24 after the Hold'em switch ablation could not open several cited evidence files (most were present elsewhere; scripts/r4.sql is absent everywhere).
