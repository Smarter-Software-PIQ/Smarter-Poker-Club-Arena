# tests/an-open-owner-window-only-notifies-its-owner.law.test.ts

Phase 3 notifies the release owner without dispatching (owner order 2026-11-09). When a booked owner window is open and a candidate has complete current evidence, `.github/workflows/owner-window-ready.yml` runs `scripts/ci/owner-window-ready.py` (which reuses the selector read-only) and opens or comments on one GitHub issue, once per window and evidence. The law fails if the workflow or any script it runs or loads calls a workflow dispatch, a repository_dispatch, `gh workflow run`, `gh run rerun` or `gh run cancel` (or their REST and Octokit forms), requests `actions: write` or `write-all`, gains a timer, or uses any action other than checkout. The release owner starts the explicit finite owner selection by hand.
