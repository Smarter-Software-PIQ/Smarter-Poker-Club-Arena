# tests/the-chairs-never-change-order.law.test.ts

A player is always drawn in his own chair. Mongo's phone (PLO8 Morning Stack, Table 1, 2026-11-05) showed BigWade in the bottom-left corner below Cali_Duncan while the engine correctly seated and acted him in seat 5, after BUTTONCHAMP, so the whole table read a wrong action order. The opponent-spacing allocator (`src/components/table/opponentAvatarLayout.ts`) had nudged his avatar past his neighbours. The law pins `opponentRingOrderKept`: the joint solver never returns a layout that changes the clockwise order of the chairs (occupied, empty and the hero's), and the DOM backstop withdraws every nudge when an applied frame does, while ordinary spacing - including the 320px ring's two top caps sliding sideways together - is left alone.
