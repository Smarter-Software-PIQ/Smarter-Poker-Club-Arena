# server/src/engine/anOmahaOpeningBluffIsPricedOnPeople.law.test.ts

The PLO4/PLO5 opening bluffs (omahaTurnBluffIsPricedOnBlockers, omahaTurnBluffIsPricedOnRangeAdvantage, omahaRiverBluffIsPricedOnRangeAdvantage) and the people-measured river answer curve (omahaRiverBetFoldIsPeopleMeasured), each default OFF, are priced on people's fold rates only (the fold table is people-only and its fit drops every Horse answer), people's multiplier is the cell shrunk to equilibrium by the street's k, the turn price never bets a pure bluff, on real audited river nodes every change is a check into a bet and off changes nothing, and no identity input exists in the modules. Since the review of 2026-11-26: the turn equity is read against the opponent's measured range on the board, not the sampler's random holdings (t3); the opponent's range table is fit from people's shown hands only and the Horse's own range is a separate Horse-only family (t4); and the people fold fit files each answer under the bettor's line exactly as the engine reads it, the last wager of the street before, dropping Horse-policy answers (t5).
