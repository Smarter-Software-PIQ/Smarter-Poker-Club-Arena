# server/src/engine/HorseHeadsUpOpenerAndLimperDefendToPrice.law.test.ts

The two default-off heads-up hold'em defence options (huOpenerDefendsToPrice for the opener facing a 3-bet, huLimpDefendsToPrice for the small blind whose limp was raised) only ever turn a fold into a call the price and the hand's equity support, fire only in no-limit hold'em cash with exactly two dealt in, and change no decision when off (2026-11-14, heads-up lane, HU-NLH-010 and HU-NLH-011).
