A Fixed-Limit River Bet Is Read As A Full Bet: With The Opt-In Option fixedLimitRiverFullBetRead On, A Horse Facing A Fixed-Limit River Wager Prices The Wagerer As Having Made A Full Bet Instead Of A Small No-Limit Bet, So Queen High And Bottom Pair Fold Heads-Up In Hold'em And One Pair Folds On A No-Low Omaha Hi-Lo Board, While Top Two Pair Continues, Second Pair Still Calls, And A Nut Low Is Never Folded; With The Option Off The Old Calls Are Still Made (SPEC-FL-01).
