# tests/a-certification-fixture-spawns-only-during-its-run.law.test.ts

A certification fixture club (owned by a reserved certification identity) materializes no tournament occurrence once it is older than the 162-minute certification stale floor: the spawn-claim INSERT into `tournament_schedule_spawns` is refused by `trg_ca_certification_fixture_spawns_only_during_its_run` with SQLSTATE 23505, which the engine's `claimSpawn` already treats as a quiet stand-down. Every certification script (`certify-club-create`, `certify-rabbit-hunt`, `certify-heads-up-rematch`) runs its fixture cleanup through `cleanupOnce` and `retireOnSignal` (`scripts/ci/certification-run-cleanup.mjs`), so a cancelled or timed-out run still retires its fixture through the guarded doors, exactly once. Added 2026-11-20 after Crest Cert 1794950026440-vqxq6 spawned empty boards for three days.
