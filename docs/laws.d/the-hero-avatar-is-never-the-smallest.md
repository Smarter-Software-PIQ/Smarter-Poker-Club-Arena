# tests/the-hero-avatar-is-never-the-smallest.law.test.ts

An opponent's rendered avatar circle may match the hero's or be smaller, never larger: the opponent painted-subject match (`--sp-opponent-art-scale`, consumed by `.seat__avatar`) is capped at the hero's own declared circle, so a hero carrying a photograph instead of character art is no longer the smallest avatar at the table (Dan 2026-11-09).
