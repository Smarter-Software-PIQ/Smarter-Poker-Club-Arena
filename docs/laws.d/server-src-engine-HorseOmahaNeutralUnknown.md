# server/src/engine/HorseOmahaNeutralUnknown.law.test.ts

With option omahaNeutralUnknown on, an unknown Omaha opponent (person or Horse, PLO4/5/6, every table size, cash and tournament) gets no presumed aggressive raise read and no bettor pressure, an opponent whose own hands show a wide raiser keeps that read, Hold'em is untouched, and with the option off the existing presumption is unchanged.
