# server/src/benchmark/SparringLearnsTheHud.law.test.ts

The sparring bench installs the lifetime opponent HUD provider for every arm and stays a measuring stick (PLO-OWNER lane REPLACEMENTS-3, Nov 21 2026): each arm and each of its two deals has its own in-memory store (SparringHud.ts) that is fed every hand's public record through the bench converter and the engine's own handRecordFromRow / applyHudHand, and the acting seat's packet is installed before every decision. Two arms with the same options still play every deal identically (OFF-vs-OFF = 0 flips, PLO4 and PLO5, heads-up and six-max); a scripted folder's fold-to-raise count in the store equals the script's own tally and the installed read moves from the prior to the scripted rate by n/(n+k); no hole card is handed to the store or found in any profile it builds; a pre-loaded store is data exported by an earlier block (never a warm-up block played in the measuring process); no runtime source imports the store.
