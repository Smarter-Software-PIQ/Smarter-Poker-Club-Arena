# server/src/engine/HorseOmahaNoBlanketRule.law.test.ts

No blanket rule decides a PLO4/PLO5 cash action when the priced rules are on (owner 2026-11-17: every decision by math, the hand, the perceived ranges, equity and EV). The register is `HorseOmahaRuleSites.ts`. The build fails when an Omaha decision option in the ledger is not classified there or its class is wrong (a categorical option without a registered default-off priced option, or the pinned list of open rules changed without this file), when a registered categorical rule site no longer hands its decision to its priced rule, when a registered categorical rule fires its receipt on the corpus of built spots and recorded production Horse decisions with every priced option on (it decided by a size, chip count, stack share, hand category, betting line or opponent label), or when the bettor's range or the realization of a call steps as the bet's share of the pot crosses a size line with the two facing-bet input options on. With the options off the same corpus fires those categorical receipts, so the third check is not vacuous.
