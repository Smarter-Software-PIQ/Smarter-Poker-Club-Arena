# tests/a-per-row-chip-ledger-lookup-carries-an-indexed-entity-filter.law.test.ts

A LIKE on a chip*ledger column whose pattern is built from each outer row (alias.column, not a p* parameter) must, in the same statement, filter that chip_ledger alias by equality on an indexed entity column (the leading column of a chip_ledger btree index), or bound the same column with a byte-wise range (~>=~ / ~<~) where a migration creates a text_pattern_ops or COLLATE "C" index on it (2026-11-24). chip_ledger holds about 30 million rows and its idempotency_key index uses the en_US collation, so an unbounded per-row LIKE seq-scans the ledger once per row: the shape that stranded Nightly 20K 10d3c9b3 on wallet_credit_idempotency (#11180, #11199).
