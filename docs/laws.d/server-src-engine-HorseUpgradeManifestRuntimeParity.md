# server/src/engine/HorseUpgradeManifestRuntimeParity.law.test.ts

The upgrade activation manifest (published on `/health`, compared between host and decision workers) must declare exactly what a decision runs. One real flop decision per variant and mode (nine variants, both modes) goes through the production path (`HandController` state, `resolveHorseHybridProfile`, worker `DECIDE_FAST`), and for every upgrade whose evidence counter fires per decision (01, 02, 06, 07, and 12 for the four games the remaining-variant pack decides) "the counter fired" must equal "the manifest declares the cell", in both directions. Guards against the brain gaining or losing a variant or mode condition without the declaration following, and against the declaration being widened or narrowed without the code. The Pineapple tournament refusal of the pack must be declared as upgrade 12's exception by its reason (`pineapple_tournament_unapproved`); every other enabled upgrade is named as table-dependent, so a new one must be classified.
