# tests/a-horse-late-prize-returns-to-its-old-club-bank.law.test.ts

Owner order 2026-11-03: a credit landing on a horse membership the club split departed returns to that club's bank in the same transaction through a declared Club Bank claim, only for split-departed records outside the horse's assigned club; any failure rolls back only the return, leaves the credit on the record and files a warning, so it can never block a payment.
