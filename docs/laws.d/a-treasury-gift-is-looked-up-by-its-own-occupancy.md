# tests/a-treasury-gift-is-looked-up-by-its-own-occupancy.law.test.ts

`smarter_private.original_treasury_participant_gift` proves only the gift witnesses that can belong to the participant's own chair occupancy. A witness whose source occupancy (`seat_event.after_row.occupancy_id`) is canonical uuid text and differs from the participant's is skipped before `original_treasury_gift_evidence` runs; a non-canonical source occupancy is still proven in full. The set of proofs, the exactly-one rule, every filter and the exception handler are unchanged, so the answer is the same answer. The cost of one lookup no longer grows with the number of witnesses, which kept the retention prune (pg_cron job 117) at ~17 s a page: `fn_pnl_cash_hand_evidence` calls it per participant, up to three times per pruned horse hand. No later migration may redefine the function without the prefilter.
