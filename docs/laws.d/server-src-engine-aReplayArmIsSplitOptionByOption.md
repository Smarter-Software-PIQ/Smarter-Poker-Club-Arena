# server/src/engine/aReplayArmIsSplitOptionByOption.law.test.ts

A replay arm runs the options it declares or the replay says so: optionSwitchSourceFromStates throws on a set this build refuses whole (naming every entry it cannot apply), optionSwitchArmFrom splits a declared or journaled set option by option (plain options applied, style options routed to the style switch, every dropped entry with its reason) and optionSwitchArmStrict refuses an arm whose declared difference cannot be applied, so an on arm and an off arm can no longer silently both run at release defaults.
