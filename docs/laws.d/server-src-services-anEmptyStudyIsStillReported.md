# server/src/services/anEmptyStudyIsStillReported.law.test.ts

The law pins that the branch is a block carrying a `reportError(..., 'HorseSelfTuner.noStats')` with the run date, that it reports rather than throws so a legitimately empty study still completes the tick, and that the context string stays unique and greppable; the window is sliced structurally from inside the branch, since the code has already moved from line 1066 to 1229.
