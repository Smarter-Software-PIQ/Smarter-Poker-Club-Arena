# server/src/engine/AHorseSlowplayIsPriced.law.test.ts

The dark zero-migration option horseSlowplayIsPriced replaces the unowned H4 monster slowplay mix with deterministic EV pricing in non-Omaha / non-Fixed-Limit flop and turn spots, stays 100% byte-identical when OFF or in Omaha / Fixed-Limit (including exact fastRandom state), fires priced check and bet receipts, and stays strictly in OPTION_SWITCH_REFUSED. Every pricing input is measured: the stab size is the pinned per-street mean pot fraction from production hand history (with provenance), the called branch uses the equity against the continuing range with the measured NLH continuation sharpness (non-increasing in the fold probability), and no free-card constant remains (board wetness is not priced).
