# tests/config/aSupersededFunctionBodyIsRefused.law.test.ts

On 2026-11-18 at 06:16 UTC a session re-ran the August migration file `20260826_tournament_rake_settlement_integrity.sql` against production. Its filename version had never been recorded (it was applied as 20260827011455), so it looked pending. It set five tournament money functions back two and a half months: `fn_settle_tournament_rake` lost rake attribution, every tournament finish was refused (incident 758cd269, reason `rake_attribution`), and a dropped rebuy overload that anon could execute came back. The database now refuses, at the statement, any `CREATE FUNCTION` whose body fingerprint is a superseded body of that function (event trigger `ca_superseded_function_body_is_refused`, SQLSTATE 55000). This law pins that guard and its fingerprints in the migrations, so it cannot be removed or weakened silently.
