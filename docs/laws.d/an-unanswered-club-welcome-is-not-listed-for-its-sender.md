# tests/an-unanswered-club-welcome-is-not-listed-for-its-sender.law.test.ts

Read on production 2026-11-18: 1,272 of one club owner's 1,299 personal Messenger threads held nothing except club welcomes that owner had sent. Pins that `fn_get_user_conversations` lists a one-to-one thread only when it holds a message that is not the viewer's own `club_welcome` (so the thread returns on any reply, or on anything the sender writes), using null-safe comparisons so an ordinary message with no metadata always counts; that groups and every earlier inbox rule are kept; that the rule never reads `is_horse` and the welcome trigger and sender never do either (CLAUDE.md 10.5: every member is sent the same welcome, and a per-member skip would tell the sender who is a horse); and that the migration is a guarded projection whose only difference from the previous definition is that predicate.
