# server/src/tournament/aPkoBustWaitsOnlyOnItsMoney.law.test.ts

Measured end-to-end PKO bust throughput through the real staged sweep, eliminatePlayer, bounty payer and four-slot elimination scheduler with several events busting at once. The next bust's read-only evidence is prefetched, its replay guard and pricing row travel with this bust's settled-marker read (after both money writes committed), and broadcasts run on an ordered queue behind the money that the pass drains before it closes, so only the door, its obligation proof, the payer and the marker proof are serial per bust. At flat 200 ms trips a saturated PKO records 44/min (50/min at 170 ms; the previous code 20.6/min), a 40/min event has no growing backlog, and four 34/min events on four slots all keep up; under the server latency measured in the incident the engine path is at least 1.6x the previous code. Hand order, unique places and fairness to peer events are asserted in every run.
