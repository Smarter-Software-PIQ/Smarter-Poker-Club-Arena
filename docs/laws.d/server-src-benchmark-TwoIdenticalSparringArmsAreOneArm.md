# server/src/benchmark/TwoIdenticalSparringArmsAreOneArm.law.test.ts

Two sparring arms with the same option set are the same arm: on the same seed and deal an OFF-vs-OFF run has exactly 0 flips and a 0.0 chip difference for PLO4 and PLO5, heads-up and six-max, because every deal of a pair is dealt on one hand clock; an arm's hands depend only on its own option set, the seed and the deal; and refused answers are counted by who acted, so a verdict's hard flag reads Horse seats only.
