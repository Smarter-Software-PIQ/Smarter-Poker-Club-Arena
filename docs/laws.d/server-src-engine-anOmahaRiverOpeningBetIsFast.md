# server/src/engine/anOmahaRiverOpeningBetIsFast.law.test.ts

The river opening bet is cheap where it applies: the fixture's applicable heads-up river nodes decided with both river opening options on cost at most 6 times the same decisions off, measured in alternating rounds against each other on the same machine (src/testing/relativeCost.ts; measured about 1.7). Offline on 1,271 applicable real spots (531 at 200 bb or deeper) the options add p95 1.1 ms (decide p95 3.4 ms, max 4.8 ms).
