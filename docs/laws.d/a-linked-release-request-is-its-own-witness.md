# tests/a-linked-release-request-is-its-own-witness.law.test.ts

The certified retirement witness in `engine-supervisor.sh` reads a run's `.request` when it has one name, or exactly two names where the second is its own sibling `.intent` (same inode, root-owned 0700 directory, nlink 2 on both): the shape the v1 launch, unit wrapper and intake publish with `ln`. Any foreign or third link stays unsafe. A committed run pinned to the old nlink-1-only bytes that parked failed while owning finalization (run 42190145714-1, 2026-11-06) is restarted by the next release's transaction before any owner check: the seal replaces only its `.intent` dirent with byte-identical private bytes so its own unit can read its request, re-enters and records its own sealed result. That step never writes a result, a seal field or authorship.
