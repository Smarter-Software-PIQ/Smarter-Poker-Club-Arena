# tests/no-css-beat-shard-is-ever-empty.law.test.ts

Every `mode: 'default'` top-level `test.describe` block in `tests/e2e/table-proportions.spec.ts` stays bounded to a single cold-fixture family so no indivisible Playwright sharding unit can outgrow a CSS Beat shard (~67 tests) and leave an adjacent shard empty. When the 69-test `cold observer and phone geometry` monolith sat in one top-level default-mode describe, shifting test counts by a few cases pushed shard boundaries so one of the 10 shards received 0 tests and tripped `scripts/ci/playwright-flaky-summary.mjs` (`the report lists no tests`). Splitting the cold families into five separate bounded default-mode groups (`cold observer canvases (2-9 seats)`, `cold phone captions, bubbles and notice containment`, `cold phone paint coverage, crowns and motion`, `observer avatar artwork allocations`, and `cold scaled phone full ring and dealer geometry`) preserves every case, assertion, timeout, and sequential worker behavior while keeping every shard balanced and the empty-report guard untouched.
