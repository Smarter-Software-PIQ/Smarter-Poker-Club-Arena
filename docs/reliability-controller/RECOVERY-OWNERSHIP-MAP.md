# Recovery Ownership Map (Reliability Controller, Stage A audit)

Read-only audit, 2026-11-09. Paths are relative to the Club Arena repo; `S/` = `server/src/`. Database facts were read with SELECT only from project kuklfnapbkmacvwxktbh (cron.job, cron.job_run_details last 24h, pg_get_functiondef). "Never" in the last column means the controller must never act on the same component; "Observe" means it may read and escalate only.

## 3. Horse decision fallback evidence path

Site: `ServerTableEngineTurns.ts:4239-4262`. `decideFast` is called inside `try`; a synchronous throw becomes a rejection. The `.catch` rethrows (no fallback counted) when the weekly pause checkpoint fails, the error is `HorseDecisionAbortedError`, the abort signal fired, or `fenceIsCurrent('fallback')` is false. Otherwise it logs `[ServerTableEngine.<tableId>.horse_decision_worker_failed]` with the error (`reportError` is `console.error` only, `S/services/errorReporter.ts:20`) and increments `poker_horse_decision_fallbacks_total`. The counter has no reason label.
