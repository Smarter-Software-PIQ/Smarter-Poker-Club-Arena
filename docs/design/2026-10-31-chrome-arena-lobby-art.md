# Chrome Arena Lobby Cards

Owner-selected Chrome Arena reference, October 31, 2026. This family is used by
MTT, cash, Spins, Sit & Go and Satellite displays, with live DOM data and existing
selection, sorting, favorite and countdown handlers.

The unedited card.png and card-featured.png masters are 1983 by 793. Their
painted bounds are x8..1974/y125..635, with the header/body seam at y407. Each
native-ratio crop paints its own box; the quilted header, icon socket, silver
price/guarantee plate and five lower data bays remain aligned. The featured
master paints a complete red perimeter. Format rails retain the requested green,
yellow, white and blue schema; Lightning cash frames are neon white.

Individual transparent sculpted icons and date-divider.png were generated from
the same selected visual reference using the built-in image generator. No runtime
text, values, statuses, guarantees, favorite stars or dates are baked into art.
The files are unedited copies of the generated masters. Original generated images
remain in the image tool output directory for this chat.
