# Current qualification input identity

`python3 scripts/ci/qualification-input-projections.py --check` verifies the actual execution and immutable admission context before native qualification. The ordinary source-binding reader invokes it automatically. It needs Python and Node builtins, with no npm installation, database or production connection.

`--write` explicitly generates the two maintained JSON inputs. It does not update their source pins, alter historical financial results, or qualify a release. Inspect the real connected change, update only the applicable current source identities with an audit reason, and run the normal affected/required gates.

The workflow projection preserves global context and exact `changes` and `accounting_postgres` jobs. The admission projection preserves the immutable Git enumerator and classifications of registered qualification inputs. Unrelated job bodies and unrelated classifier branches are outside those identities. Unsupported dependencies or YAML anchors/aliases are refused until their closure is implemented and tested. Unknown classifications must retain every suite.

Financial SQL, fixtures, executable validators and original qualifications retain their established byte pins. These projections prove input identity and admission behavior; they do not prove that any financial assertion executed or passed.
